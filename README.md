# 奶龙保卫战 · v0.5.3 手机与电脑浏览器

TypeScript + Phaser 3.90.0 + Vite。以本机 Steam《王国保卫战》初代 Build 24662480 的关卡和数值为基准，使用项目自己的奶龙与场景素材。

在线试玩：https://chenyehuan1234.github.io/nailong-defense/ 。手机请横屏战斗，选关与其他菜单可以竖屏浏览。操作、适配与验证记录见 [手机说明](docs/mobile-v5.md)。手机、本机与线上站点的存档分别保存；可在设置中导出／导入迁移。

iPhone要去掉浏览器上下工具栏：用Safari打开游戏 → 分享 → 添加到主屏幕（若有“作为Web App打开”，保持开启）→ 从奶龙图标启动。Android使用浏览器菜单中的“安装应用／添加到主屏幕”。游戏里的“全屏游玩”提供引导；内置浏览器自身工具栏不能由网页强行隐藏。

## 启动

在本目录运行（Node.js 22.19 或更新版本）：

```powershell
npm install
npm run dev
```

开发版：http://127.0.0.1:5188/ 。静态版：

```powershell
npm run build
node tools/serve-dist.mjs
```

静态版：http://127.0.0.1:5189/ 。`dist/` 已包含本地图片、音乐、音效和程序，运行时不读取原作安装目录。

## 操作

| 操作 | 方法 |
| --- | --- |
| 建造、升级、出售、购买塔技能 | 点击塔位或塔楼 |
| 快速建造 | 选中空塔位后按1–4 |
| 集结点 | 营地／岩石守卫塔 → 集结点 → 范围内道路；面板暂时收起 |
| 英雄移动 | H或英雄头像，点击战场；Shift点击追加路线 |
| 援军／流星奶弹 | Q／W，随后选择落点 |
| 开波／暂停／取消 | N／空格／Esc |
| 速度／自动开波 | 右上角按钮；支持1／2／3倍速 |
| 手机地图 | 单指拖动、双指缩放；右侧＋／−／适屏；点击地图执行当前指令 |
| 单位信息 | 点击英雄、卫兵或怪物，底部直接显示实时属性 |
| 原作波间时钟 | 设置 → 波次节奏；默认清场后3秒 |
| 冰封与封印 | 按实际提示点击解除；冰封三次 |
| 精灵／雪人 | 点击营地招募；雪人先用流星解冻，阵亡后免费补员 |
| 阳光神殿 | 招募后点击设施，再选敌人；Shift继续招募 |

第一波手动开始。清场模式需等预定出怪结束且所有存活、召唤、分裂和延迟复生敌人处理完毕，再等待3秒游戏时间；主动暂停或浏览器挂起页面时停止推进。手动提前开波保留金币和冷却奖励。

## 关卡工坊

现有1–100关战役编辑、道路、塔位、波次、设施、预设塔、撤销重做、JSON导入导出与连续试玩继续可用。未修改的原作布局与有序时间线可完整保存。修改某波敌人组只替换该波时间线；修改道路后转为编辑器道路规则，避免继续使用旧子道路和通行网格。编辑器、动作测试不增加玩家图鉴或主线星数。

角色与动画沿用现有素材，本轮优先机制，不做13英雄或全部敌人的逐角色动画重制。场景保留准确逻辑布局，当前植被、建筑和地形绘制仍有进一步打磨空间。
