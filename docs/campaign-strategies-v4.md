## 复现方法

`npx vitest run tests/balance.test.ts`。三个种子各有保存的获胜策略，回归时重新运行战斗，不直接读取旧胜负作为测试结果。

第21关可采用雷霆工坊起手，在下方汇流塔位建立过载清群火力，另补对空游侠和森灵削甲。祖灵英雄的变熊免伤能承担恶魔爆炸及精英压力。法术按密集敌群的预计行走位置释放。整套购买和资源账本以报告为准。

自动策略用于检查闭环与数值可通关性，浏览器检查另行覆盖实际点击。尚不能据此断言26关都具有多种同等有效的打法。
