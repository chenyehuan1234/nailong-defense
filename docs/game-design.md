# v0.2 游戏规则、架构与工坊

## 战役与挑战

十二关按顺序解锁。战役20生命，剩余18–20生命三星、6–17二星、1–5一星；三星后开启该关两个挑战。英雄挑战六波、铁人挑战一条长波，均只有一生命，并分别限制塔等级、星级、英雄和可建塔系。挑战各奖励一星。

休闲／普通／老兵分别将敌人生命设为基础值的80%／100%／120%。难度和模式分别选择。英雄全部免费；前九关挑战禁用英雄，后三关可选。存档按战役、关卡、模式记录最佳成绩；挑战使用36颗战役星以内的升级分配完成验证。

## 战斗与调度

兵营三名奶龙，每名拦截一个地面敌人；升级时恢复生命，阵亡后按兵种和升级补员。飞行单位绕过拦截。物理伤害受护甲影响，魔法受魔抗影响，爆炸忽略一半护甲并有边缘衰减，毒伤与燃烧是真实伤害。同类状态刷新时间、保留较强强度；召唤和分裂幼体不给重复奖励。

英雄每关从一级重新成长，攻击和技能获得经验，最高十级；二级、四级开启两项自动技能。团团拦截两个目标，守护时减伤并反击。手动移动优先于战斗，可脱离接敌并使用Shift排路线；近战英雄在锚点附近自动追击。寻路只传递坐标，不能将目标实体的属性写入英雄。英雄阵亡后15秒复活，暖暖18秒；脱战恢复生命。空场等待不能刷医师技能经验。

援军基础冷却10秒、存活20秒；流星基础冷却80秒，经升级降至70／60秒，并增加弹数、火场和范围。流星有落点预警，不攻击飞行目标。第一波手动开始；自动模式在预定出怪结束且全部敌人处理后等待3秒游戏时间开波，开关自动重置计时，暂停或失焦冻结。波间停止周期设施出怪。自动开波不提供提前奖励。提前开波按剩余等待时间奖励金币（最多60），并缩短两种主动技能冷却。

Boss不能被永久控制或拦截。齿轮巨兽召唤傀儡；冰冠冻结最多四塔15秒，每塔点击五次解除；荆棘魔王有两条完整生命，先显示可点击解除的封塔预告，再禁用塔。Boss漏过直接失败，结算只发生一次。

## 地图设施

矿洞捷径跳过部分道路。墓地把特定人形尸体转为无奖励亡灵；召唤阵与岩浆入口在指定波次后周期出怪。王城有预设奶龙守卫，城堡铁人挑战另有三座预设三级法塔，不能新建法塔。

精灵营地最多招募四名支援奶龙。冰封雪人须用流星融化后支付400；2500生命、单体拦截、50–110范围攻击、2.5秒攻击间隔，阵亡后需重新购买。阳光神殿最多招募四位施法者，随后手动指定落点，人数影响伤害和冷却。友方特殊单位也使用奶龙外观。

## 工坊数据

整套战役为CampaignDefinition v2，包含1–100个ID唯一的LevelDefinition。每关最多六条道路、每路2–60节点、80塔位、100波、每波20组、每组150敌人，整关总数不超过10000。第一和最后道路节点就是入口出口；自动道路绘制和实际规则使用同一曲线。

波次组字段：type敌人键、count数量、path道路索引（0起）、interval间隔秒、delay相对该波开始的延迟。rest从该波最后一个预定出生时间计起，可以与未清理敌人重叠。障碍、捷径、设施和预设塔均可使用高级JSON配置。新建额外关卡默认开放全部高级分支，再自行限制塔等级。

工坊350ms延迟自动保存本机草稿。当前关卡几何与波次保留80步历史；战役数量／顺序调整不提供跨关撤销。导出整套JSON作为长期备份；不会自动覆盖磁盘源文件。试玩整套战役包含连续结算和下一关，自定义成绩不贡献主线星级。

主线v2与旧三关v1分别保存。迁移保留旧成绩和旧升级记录，不把旧地图成绩当成新主线通关。只保存进度、升级、英雄和设置，不保存战斗途中状态。导入校验版本和点数；不支持或损坏的本机v2数据先保留备份再建立新存档。
