# v0.4.1 交互修复 · 2026-10-02

本轮落实五项交互反馈和追加的左键拖选问题，沿用v4存档与现有战役规则，不重置战役进度或关卡作品。

## 单位底部信息

点击战场上的敌人、英雄或士兵，在画面底部显示头像、名称、当前生命、伤害区间、护甲、攻击类型或魔抗、移动速度和能力摘要。敌人额外显示漏怪损失、弱点及控制状态；英雄显示等级和技能等级，卫兵显示兵种及营地来源。数值读取实际战斗状态，生命、削甲、强化、复活及升级会更新。

选中单位有脚下圆环。选中英雄后仍可点击地面移动，Shift追加路线。技能和集结点落点优先于单位查看；点击塔位进入建造，Esc或信息栏关闭按钮收起信息。敌人死亡后清除信息；变羊可通过信息栏按钮击破。

## 暂停与滚动

- 移除窗口失焦、页面隐藏时自动弹出的暂停窗口。点击浏览器外部或其他面板不会要求手动恢复；暂停按钮、空格、设置和阅读窗口仍按主动操作暂停。
- 音乐在可见页面失焦时继续；真正隐藏页面后停止，返回续播。浏览器隐藏页面时的帧调度暂停不会生成游戏暂停窗口。
- 选关右侧说明文字、空白区域和英雄列表均接收滚轮。英雄与难度选择保留右侧滚动位置，选择另一关回到关卡说明顶部。
- 禁止游戏标题、提示、面板文字及图片被浏览器原生拖选或拖出，避免左键拖动后出现蓝色选中文字。输入框、JSON文本区和可编辑文本仍支持选择、复制；工坊面板与地图节点的拖动保留。

## 工坊

新作品默认提供26关可编辑参考战役。旧作品的关数、名称与内容保留；“26关参考模板”可以向旧作品追加任意一关，也可以替换当前关并撤销。当前关卡下拉框切换整套作品的关卡，保存、导出与试玩使用当前关卡数据。

拖动面板顶部绿色标题栏可改变位置，也支持方向键微调，Shift加大步幅。“面板归位”恢复右侧。拖动按1600×900逻辑坐标换算，因此缩小窗口仍能正确移动。编辑点击依据面板实际范围判断，面板移走后原右侧区域可以放置节点与塔位。面板重新显示时保留滚动位置，超多道路按钮换行。

修复控件失焦触发change时的重复面板刷新；设施类别选择也不会被无关表单刷新覆盖。

## 首页图片

使用内置image_gen生成一张完整冒险插画，替换首页旧的四张悬浮头像。左侧保留菜单文字空间，右侧为奶龙职业队伍，背景连接森林、木桥、雪山与城堡。

- 运行资产：`public/assets/home-v4.1.webp`，1600×900。
- 原始输出：`art/source/home-v4.1.png`。
- 工具、参考图与完整提示词：`art/source/home-v4.1.json`。

`tools/interaction-v41-qa.mjs`在Chrome、Edge的独立测试配置中进行真实鼠标检查：文字与英雄列表空白区域滚动、选择英雄后保持滚动位置、旧作品追加第26关、修改两关金币并刷新复核、替换与撤销、拖动面板、缩放拖动、移动面板后在右侧加塔位、敌人／卫兵／英雄点击、实时HP和护甲、英雄移动、失焦不暂停及手动暂停。另覆盖拖动战场标题和提示不产生文字选择，以及关卡名称和JSON仍可选择文字。报告见 `test-results/interaction-v41.json`，截图见 `test-results/visual-v41/`。

使用专门构造的单位与已解锁测试档检查交互；没有修改玩家浏览器的存档。战役数值与出怪规则未变，本轮不重复此前78场通关模拟。静态版另用 `tools/production-qa.mjs`核对本地资源、开波、倍速、存档和音乐读取。
