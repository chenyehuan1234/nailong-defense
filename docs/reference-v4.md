1. 造型使用奶龙及项目素材；地图道路和逻辑地标来自参考，背景绘制与大地图底图并非原作场景画面。按用户要求暂缓逐角色动画重制。

3. 通用弹道、施法准备／命中延迟、索敌与追击仍由项目表现和规则实现；部分持续伤害按连续时间计算，部分原作脚本表现做了简化。数值和关键能力核对不能替代逐帧实战完全一致性。
4. 自动清场3秒、三倍速、中文侦察、独立训练营及关卡工坊是项目功能。

以上差异不影响26关、13英雄和战役闭环使用；后续如追求逐帧还原，应继续独立核对命中时间、AI选取、事件共享随机数和场景绘制，不应把当前自动通关记录称为百分之百复刻。
