# 奶龙保卫战 v0.4.1

26关战役、13位英雄与完整长曲音乐，加入底部单位信息，修复失焦暂停、选关滚动及左键拖选。工坊可编辑26关模板，拖动面板标题即可移动位置；首页使用新冒险插画。

需要Node.js 22.19或更新版本。在此文件夹打开终端，运行：

    node serve-dist.mjs

然后打开 http://127.0.0.1:5189/ 。也可以双击「启动游戏.cmd」。

端口被占用时，在PowerShell运行：

    $env:PORT=5190
    node serve-dist.mjs

随后打开 http://127.0.0.1:5190/ 。资源全部在dist内，运行时无需原作安装。

现有v4战役进度和编辑器作品保留。首次从v1–3升级至v4时才按之前的计划重置旧战役；原设置与编辑器作品保留。浏览器、端口不同的本机存档相互独立；在游戏设置中导入／导出迁移。

点击敌人、英雄或士兵查看底部实时信息；点击塔位建塔。H选择英雄，Shift点击追加路线，Q援军，W流星，N开波，空格主动暂停，Esc取消。右上角调整1／2／3倍速，设置可选择清场3秒或原作波间时钟。点击窗口外部不会弹出暂停。

工坊「当前关卡」选择需要修改的关；26关参考模板可追加或替换当前关。标题栏可拖动，也支持方向键微调，Shift加大步幅。游戏文字不会被拖选，输入框和JSON仍支持选择复制。

本轮改动与检查：interaction-v4.1.md。战役验证、策略与已知实现差异：verification-v4.md、campaign-strategies-v4.md、reference-v4.md。音乐与音效来源和授权：dist/assets/audio/CREDITS.md。
